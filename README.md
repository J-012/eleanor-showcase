# Eleanor

Public showcase for **Eleanor**, an ongoing team project developed in collaboration with Human Learning Lab.

Eleanor is a learning tool designed around live and near-live transcription, captured learning moments and AI-generated summaries. The full source repository is private while the project is still under development, so this repository only presents the project at a high level.

## My role

I work as both **project lead and developer** in a multidisciplinary team.

My contributions have included work on:

- session and participant flows
- organizer and participant pages
- transcription functionality, including language handling
- Firebase-backed application functionality
- improving and integrating features across the shared codebase
- coordinating development work and helping the team keep a common technical direction

## Technology

- Next.js
- React
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Speech recognition / transcription
- AI-generated summaries

## Team development

Eleanor is developed collaboratively using Git and GitHub. My work in the private repository includes multiple merged pull requests and contributions to shared features.

Working on the project has given me practical experience with developing inside an existing codebase, coordinating changes with other developers, resolving integration issues and explaining technical decisions within a team.
